Clothing Store Page

What it is: this is a mini clothing store webpage where you can browse through a selection of clothes and then purchase them at checkout.

How I did it: I used HTML, CSS, and JavaScript while following a tutorial.

The Challenges I faced: The JavaScript was a little challenging to follow along with since Im still new with it. I can't say that I am entirely comfortable with it but I will continue to practice with it.

What I learned: I learned how to make a clothing catalog with html. Learned a few new attributes and tags.
